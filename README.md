# 📡 ISEN-AP4 - TP N°1 : Programmation des Objets Connectés

Bienvenue dans le TP1 de Programmation des Objets Connectés, proposé dans le cadre du module ISEN-AP4. Ce travail pratique a pour but de vous familiariser avec l’éditeur de texte `nano`, le langage Python 3 et le terminal sous environnement Linux.

## 🎯 Objectifs pédagogiques

- Utiliser un éditeur de texte en ligne de commande (`nano`)
- Écrire et exécuter des scripts Python
- Comprendre les structures de base de Python : affectation, conditionnelle, boucle, listes, chaînes, fonctions
- Manipuler des données alphanumériques
- Travailler avec des fonctions prédéfinies et utilisateur

---

## 🖥️ Modalités

- **Durée :** 4 heures  
- **Travail :** Individuel ou en binôme  
- **Évaluation :** Non notée

  ```bash
  ssh [identifiant]@10.34.164.21
  ```

## 🧰 Configuration de l'environnement

### 🔹 Configuration recommandée de nano (`~/.nanorc`)
```bash
SET AUTOINDENT
SET TABSTOSPACES
SET TABSIZE 4
```

---

## 📘 Contenu du TP

Les exercices sont répartis en plusieurs thématiques :

### 1. 📏 Affectations et types
- Affectations multiples
- Opérations avec les types `int` et `float`
- Utilisation de `type()`

### 2. 🔁 Structures conditionnelles et boucles
- Conditions (`if`, `elif`, `else`)
- Boucles `while` et `for`
- Tables de multiplication, conversions, suites géométriques
- Exercice emblématique : le riz sur l’échiquier ♟️

### 3. 🔤 Manipulation de chaînes
- Présence et comptage de caractères
- Inversions, palindromes
- Fonctions de traitement de texte

### 4. 📋 Listes
- Création et manipulation
- Recherche de valeurs, tris, filtrage par critères

### 5. 🧮 Fonctions
- Fonctions simples avec arguments
- Fonctions avec valeurs par défaut
- Fonctions avancées : remplacement de caractères, recherche d'index

### 6. 🔍 Révisions & Compréhension
- Analyse de scripts
- Conditions complexes
- Recherche de multiples et bornes

### 7. 🧠 Bonus : Fonctions avancées
- Fragmentation de chaînes
- Recherche d’index inversée
- Détection de majuscules et de chiffres
